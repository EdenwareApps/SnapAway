# src/iap/winrt — Projeção C++/WinRT do Microsoft.Services.Store.Engagement

Esta pasta contém cabeçalhos de projeção **C++/WinRT gerados** a partir do
metadados WinRT (`Microsoft.Services.Store.Engagement.winmd`) do SDK oficial
**Microsoft Store Services Engagement** (pacote NuGet
`Microsoft.Services.Store.Engagement` v10.2307.3001).

Os arquivos foram gerados pelo `cppwinrt` (v2.0.190620.2) e **não devem ser
editados manualmente** — todos iniciam com o aviso
`WARNING: Please don't edit this file. It was generated by C++/WinRT`.

## Por que estão versionados

- `binding.gyp` referencia `winrt` em `include_dirs`.
- `iap-addon.cpp` faz `#include <winrt/Microsoft.Services.Store.Engagement.h>`.
- Não há passo de geração automática no build; sem esses cabeçalhos o addon
  nativo não compila, portanto eles são vendidos (committed) no repositório.

## Origem / Regeneração

O SDK em si **não** é versionado (ver `.gitignore` — `src/iap/sdk/` e
`src/iap/sdk-runtime/` ficam fora do repositório público e são obtidos do
NuGet). Para regenerar estes cabeçalhos a partir do SDK:

```powershell
# 1) Restaurar o SDK do NuGet (ex.: extrair o pacote baixado)
nuget install Microsoft.Services.Store.Engagement -Version 10.2307.3001

# 2) Gerar a projeção a partir do .winmd para esta pasta
cppwinrt -in <caminho-para>/Microsoft.Services.Store.Engagement.winmd `
         -out src/iap/winrt

# 3) Conferir a versão do cppwinrt usada (deve casar com o static_assert
#    CPPWINRT_VERSION nos cabeçalhos: 2.0.190620.2)
```

> Nota: a projeção depende dos cabeçalhos base do C++/WinRT do Windows SDK
> (`winrt/base.h`, `winrt/impl/Windows.*.h`), que vêm do próprio SDK do Windows
> e não são vendidos aqui.
